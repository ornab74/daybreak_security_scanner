# Daybreak experimental research track

These are high-potential, uncommon research directions—not claims of globally
unique inventions and not production findings. Each must earn promotion through
an adversarial corpus, false-positive measurement, deterministic evidence, and a
clear explanation contract.

1. **Counterfactual Guard Mining** — Compare sibling handlers and detect the one
   path missing a normally universal authorization, validation, or tenancy guard.
2. **Trust-Boundary Tomography** — Reconstruct layered input-to-privilege
   boundaries from partial evidence and visualize where validation becomes thin.
3. **Exploit Preconditions Lattice** — Represent attacker requirements as a
   lattice so individually weak signals can form one calibrated attack path.
4. **Invariant Drift Radar** — Learn repeated security invariants across languages
   and identify implementations that silently diverge from the repository norm.
5. **Negative-Space Diffing** — Detect vanished security checks even when code is
   renamed or structurally rewritten rather than textually deleted.
6. **Attacker Budget Scoring** — Estimate exploit cost in requests, timing, access,
   knowledge, and infrastructure instead of reducing risk to one severity label.
7. **Privilege Half-Life** — Measure how long elevated authority survives beyond
   the operation that required it.
8. **Dormant Route Awakening** — Find code reachable only under rare feature-flag,
   plugin, deserialization, fallback, or deployment combinations.
9. **Secret Lineage Graph** — Trace credentials through logs, caches, telemetry,
   subprocesses, copies, and cleanup to expose secondary leakage.
10. **Configuration Contradiction Solver** — Combine app, proxy, cloud, and
    deployment settings to identify protections canceled by another layer.
11. **Dependency Capability Delta** — Review upgrades by newly gained network,
    process, filesystem, lifecycle-hook, and native-code capabilities.
12. **Semantic Security Checksums** — Fingerprint guard meaning so safe refactors
    remain stable while subtle security weakening changes the checksum.
13. **Remediation Blast-Radius Forecast** — Predict callers, protocols, and
    compatibility assumptions likely to be disturbed by a proposed fix.
14. **Security Debt Interest** — Rank weaknesses by expected attack-surface growth
    as callers, permissions, routes, and dependencies accumulate.
15. **Patch Immune System** — Generate safe adversarial mutations around a fix and
    reject patches whose security invariant breaks too easily.

## Promotion gate

An experiment should become a scanner engine only after it has fixtures for true
and false cases, confidence calibration, bounded resource use, stable fingerprints,
redacted evidence, SARIF mapping, and a documented suppression strategy.

## Implemented forecast derivatives

The prospective dependency-risk lane now prototypes five derivatives of the
original future-risk idea. They remain forecasts—not vulnerability findings:

1. **Temporal Risk Curve** — Produces mutually validated 1-, 6-, 12-, and
   36-month bands instead of hiding change behind one selected date.
2. **Control-Adjusted Risk Gap** — Separates inherent package hazard from residual
   deployment risk and identifies the highest-leverage compensating control.
3. **Epistemic Ledger** — Keeps sourced observations, bounded inference, and
   critical unknowns in different schema fields.
4. **Scenario Stress Test** — Compares base case, patch-lag, and ecosystem-shock
   conditions with explicit preconditions, signals, and mitigations.
5. **Early-Warning Watch System** — Converts the forecast into measurable
   metric/trigger/response triplets that can drive future reassessment.

Schema validators reject missing/duplicated timepoints or scenarios, a headline
that disagrees with the selected horizon, and residual risk higher than inherent
risk after applying controls.
